# CourtSync

CourtSync is a unified open-source monorepo for volleyball tournament scoring, tournament scheduling, and pickup game coordination.

## Monorepo structure

```text
courtsync/
├── apps/
│   ├── tournament/
│   ├── scheduler/
│   └── coordinator/
├── packages/
│   ├── core/
│   ├── ui-components/
│   └── shared-hooks/
└── docs/
```

## Getting started

1. Install pnpm.
2. Run `pnpm install`.
3. Run `pnpm lint && pnpm test`.
